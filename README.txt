WRITING REVIEW - install and share
==================================

Files: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png
Keep them together in one folder.

1) Put the folder online (free, about 2 minutes). An app can only be installed
   from a web address (https), not from a file on your phone.
   - Netlify: go to app.netlify.com/drop and drag this folder onto the page.
   - GitHub Pages: upload the files to a repository, then Settings > Pages.
   - Vercel: import the folder or run "vercel" inside it.

2) Install it:
   - Android / Chrome / Edge: open the web address, then Settings (in the app)
     > Install app, or use the browser menu > Install app.
   - iPhone (Safari): Share button > Add to Home Screen.

3) Let other people join:
   Open the app > Settings > Share (QR). Show the QR code or tap Share / Copy link.
   Everyone uses their own free Gemini key (aistudio.google.com/apikey).
   Keys stay in each person's own browser and are never shared.

4) Gemini free plan: about 20 requests a day.
   The app counts requests (shown above the text box), warns you at 3 left,
   and stops before you go over. A typed text of up to about 330 words uses 1 request.
   Reading a handwritten photo uses 1 to 3 requests (Settings > Photo reading size).
   The count resets around midnight Pacific time.
